Redis-Lite

A Java and Spring Boot project exploring Redis-style operations through a REST API, with an in-memory cache and MongoDB persistence.

  • Key-value operations — Endpoints for setting, retrieving and deleting values.
  • Cache and persistence — Reads check an in-memory map before querying MongoDB; writes save to MongoDB before returning.
  • Expiry and TTL — Endpoints to set key expiration and inspect the remaining time to live.
  • Sorted-set operations — Endpoints for adding scored members, looking up ranks and retrieving members within a score range.

DataLens — CSV Dashboard

  • Built-in chart builder with 6 chart types, custom aggregations and color palettes.

  • Built with vanilla JS, Chart.js and PapaParse — zero dependencies to install.
